# Модуль 7a. Дисплей

## Выбор (пожелание пользователя: «дёшево, но крупно»)
| Вариант | Размер / разрешение | Интерфейс | Плюсы | Минусы | Статус |
|---|---|---|---|---|---|
| **ILI9488** | 3.5" 480×320 | SPI | самый дешёвый крупный, распространён | по SPI только 18 бит/пиксель (3 байта) → полный кадр ≈ 90 мс при 40 МГц; у многих модулей SDO не отпускает шину (MISO не подключаем); чаще TN-матрица | **по умолчанию** |
| ST7796S | 4.0" 480×320 | SPI | 16 бит по SPI → ~60 мс полный кадр, крупнее; бывают IPS | чуть дороже | альтернатива |
| RGB-панель (ST7701/ST7262 и т. п.) | 4.3"/5" 800×480 | параллельный RGB (ESP32-S3 LCD) | плавная графика, крупно | **16–20 GPIO** + PSRAM-буфер кадра → только своя плата/модуль «ESP32-S3 + экран» | путь развития |
| SSD1306/SH1106 | 0.96–1.3" 128×64 | I2C | минимум проводов | мелко | запасной |

LVGL обновляет только изменённые области, поэтому для приборки (цифры скорости/SoC) 10–20 кадр/с на SPI достаточно.

## Читаемость и защита
- **IPS предпочтительнее** (углы обзора, контраст); для солнца — модули с повышенной яркостью подсветки и/или трансфлективные; антибликовая плёнка.
- **Подсветка — ШИМ** (GPIO39, 12 кГц) по датчику освещённости: днём 100 %, ночью ~15 % (не слепит); логарифмическая шкала (`ui::backlightPct`).
- Тёмная тема, крупные шрифты (скорость 48+ пт), цветовые предупреждения (красный — неисправность, жёлтый — внимание).
- **Влагозащита:** корпус IP65 с окном из поликарбоната/акрила 2–3 мм, оптический клей или уплотнитель по периметру, дыхательный клапан (Gore-вент) против запотевания, гермоввод кабеля; не оставлять на солнце без защиты (TFT темнеет > 60–70 °C).
- Тач (XPT2046) не используется — управление кнопками руля (перчатки, дождь).

## Подключение (SPI, через GPIO-матрицу)
| Сигнал модуля | GPIO ESP32-S3 | Примечание |
|---|---|---|
| SCK | 6 | до 40 МГц |
| MOSI (SDI) | 7 | |
| MISO (SDO) | — | не подключать |
| DC (RS) | 16 | |
| CS | 21 | |
| RESET | к RC-сбросу / EN | свободных GPIO нет; вариант — линия PCA9555 |
| LED (BL) | 39 → MOSFET/транзистор | ШИМ подсветки, ток подсветки 3.5" ~ 60–120 мА |
| VCC | 3.3 В (или 5 В, если на модуле стабилизатор) | проверить перемычку J1 на модуле |
| GND | GND | |
Кабель до руля ≤ 30–40 см, экранированный/витые пары с GND; при сбоях — снизить частоту до 27 МГц.

## Программная часть
- Слой абстракции `DisplayHal` (`firmware/lib/display/display_hal.h`): `begin / setBacklight / render(screen, state)`.
- Бэкенды: `LogDisplay` (консоль, по умолчанию), `LvglDisplay` (LVGL 8.3 + LovyanGFX, окружение `esp32s3_lvgl`, `-DUSE_LVGL`), план — OLED (U8g2).
- LVGL: `include/lv_conf.h`, 16 бит цвет, 2 DMA-буфера 480×40 во внутренней RAM, тёмная тема, Montserrat 14/20/28/48. **Кириллица** — свой шрифт через `lv_font_conv` (DISP-04).
- Выбор панели: `CFG_DISPLAY_TYPE` = `DISPLAY_ILI9488_SPI` | `DISPLAY_ST7796S_SPI` | `DISPLAY_I2C_OLED`.

## Экраны
| Экран | Содержимое |
|---|---|
| **Главный** | скорость (крупно), итоговый SoC (полоса + %), остаток км (по Вт·ч/км), иконки: свет/авто, поворот, стоп, дальний, подогрев, «зажигание», предупреждения |
| **Батарея** | V, I, P, SoC, остаток А·ч, Вт·ч/км, температура шунта |
| **Сборки** | A и B: online, SoC, I, V, ячейки min/max/Δ, температуры, MOSFET, флаги защит, разбаланс |
| **Свет/Комфорт** | режим OFF/AUTO/ON, lux, фара, режим днища, яркость; уровень подогрева, T ручек |
| **Поездка** | км, время в движении, ср. скорость, Вт·ч, Вт·ч/км; долгое «M» — сброс |
| **Зарядка** | открывается сам при токе заряда > 1 А: ток, мощность, SoC, время до полного, T ячеек, ΔV; источник данных о станции — ветка `charger-gbt` |
Навигация: «+/−» (или «M» коротко — следующий), «назад» — на главный; автоматический возврат на главный при начале движения.
