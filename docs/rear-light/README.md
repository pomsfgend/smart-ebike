# Модуль 4. Задний стоп-сигнал и поворотники на адресной ленте

## Раскладка ленты (по умолчанию 30 св.)
```
 индекс:  0 ........ 9 | 10 ............ 19 | 20 ....... 29
         [ ЛЕВЫЙ ПОВ. ] [ ГАБАРИТ / СТОП    ] [ ПРАВЫЙ ПОВ. ]
 бегущий огонь: ←—— наружу           наружу ——→
```
`CFG_LED_REAR_COUNT`, `CFG_REAR_TURN_SEG` в `config.h`. Если лента установлена «вверх ногами» — флаг инверсии (REAR-03).

## Логика
| Состояние | Центр | Боковые сегменты |
|---|---|---|
| свет выкл, без тормоза | выкл | выкл |
| основной свет вкл | габарит красный ~25 % | габарит ~25 % |
| тормоз | **стоп красный 100 %** | 100 % красный (если нет поворота) |
| поворот L/R | как выше | сегмент поворота — янтарная бегущая заливка 1.5 Гц, в паузе — чёрный |
| аварийка | как выше | оба сегмента мигают |

- Приоритет: поворот (в своём сегменте) > стоп > габарит. В сегменте поворота красный не рисуется — сигнал однозначен.
- Частота мигания 90/мин (`CFG_BLINK_PERIOD_MS = 666`), первая вспышка мгновенно.
- **Тормоз:** датчики в ручках L/R (геркон/Холл/концевик, обычно те же, что отключают мотор) → оптопары → GPIO14/15, ИЛИ.
- Опции (REAR-04): «экстренное торможение» — мигание стопа 4 Гц при замедлении > 6 м/с² (по скорости от контроллера мотора/акселерометру).

## Безопасность
- Задержка тормоз → свет ≤ 50 мс (замер — REAR-01).
- Fail-safe (REAR-05): при сбое прошивки стоп должен работать — аппаратный резерв (отдельный красный LED-модуль от сигнала тормоза через транзистор) и/или watchdog с быстрым рестартом.
