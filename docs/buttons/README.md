# Модуль 7b. Кнопки на руле

У пользователя **готовый пульт кнопок** — модель и число кнопок пока **неизвестны**. Модуль сделан универсальным.

## Варианты подключения (бэкенды)
| Бэкенд | `CFG_BUTTONS_BACKEND` | Когда | Выводы |
|---|---|---|---|
| **PCA9555** (по умолчанию) | `BUTTONS_BACKEND_PCA9555` | любой пульт с отдельными проводами на кнопки (общий провод + по жиле на кнопку) | I2C, P0.0–P0.7 (до 8 кнопок) |
| ADC-лестница | `BUTTONS_BACKEND_ADC` | пульт уже с резисторами (2–3 провода на все кнопки), или чтобы сократить жилы до руля | GPIO2 (вместо LDR) |
| Прямые GPIO | `BUTTONS_BACKEND_GPIO` | только без SPI-дисплея (выводы 6/7/16/21/39 общие с TFT) | 5 GPIO |
Расширитель PCA9555 **обязателен в любом случае** — порт P1 занят силовой частью (предзаряд, kill, aux, зуммер, клаксон, подогрев).

## События и назначения
- Антидребезг 20 мс; события **Press / Short / Long (800 мс) / Repeat (250 мс)**.
- Тип кнопки: **Momentary** (нажал–отпустил: поворот переключается по нажатию) или **Level** (фиксируемый рычаг/тумблер: важен уровень контакта).
- Таблица по умолчанию (`kDefaultMap`, переназначается в NVS после уточнения пульта):

| # | Кнопка | Короткое | Длинное | Автоповтор |
|---|---|---|---|---|
| 0 | ← | поворот влево (toggle, по нажатию) | — | — |
| 1 | → | поворот вправо | — | — |
| 2 | ⚠ | аварийка (toggle) | — | — |
| 3 | ☀ | свет OFF → AUTO → ON | дальний | — |
| 4 | 📯 | клаксон (пока нажата) | — | — |
| 5 | M | меню / следующий экран | сброс поездки | — |
| 6 | + | вверх | — | да |
| 7 | − | вниз | режим днища | да |
| — | ⏻ / подогрев | `PowerToggle` («зажигание»), `GripCycle` — назначить, когда станет известен пульт | | |

- Повороты: автосброс через 20 с для кнопок без фиксации (`CFG_TURN_AUTO_OFF_MS`).
- **Тормоза не идут через модуль кнопок** — только прямые GPIO14/15 (минимальная задержка, независимость от I2C).
- Если на пульте 3-позиционный переключатель света — два контакта с типом Level и действиями `LightAuto` / `LightOn`.
