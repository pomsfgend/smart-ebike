# Модуль 5. Передние электронные поворотники

## Железо
- Две короткие ленты (по умолчанию по 8 св. SK6812/WS2812B) — на концах руля или по бокам фары. GPIO12 (L), GPIO13 (R).
- Лучше в рассеивателе (матовый поликарбонат), IP67. Кабель от контроллера по рулю — 3 жилы, разъём Higo/Julet.
- Индекс 0 — ближе к центру, бегущий огонь идёт наружу.

## Логика
- Мигание синхронно с задними и днищем (общая фаза). Аварийка — обе стороны.
- Когда включён основной свет — тусклый янтарный «габарит» (≈15 %) на обеих сторонах (по желанию — выключаемо, FRONT-03).
- Белые/красные цвета на передних лентах **не используются** (белый — только фара/ДХО, красный спереди запрещён).
- Звуковое подтверждение — активный зуммер на PCA9555 P1.6 (тиканье по фронтам).
- Автосброс поворота (FRONT-04, опц.): если переключатель без фиксации — по таймеру 20 с или по возврату руля (нужен датчик).
