# Модуль 3. Подсветка днища (underglow)

## Железо
- Лента **WS2812B** (RGB) или **SK6812** (RGBW — лучше «тёплый белый» для режима Follow), IP67 в силиконе, 60 св/м.
- По умолчанию 120 светодиодов: левый борт 0–59, правый 60–119 (индекс 0 борта — у рулевой колонки). Задаётся `CFG_UNDERGLOW_*`.
- Линия данных GPIO10 → 74AHCT125 → 330 Ом → DIN; питание 5 В с двух концов (≥ 1 мм² / 18 AWG), 1000 мкФ на входе.
- Худший ток 120 × 60 мА = 7.2 А → программное ограничение `CFG_LED_MAX_MA` (3 А на все ленты) + предохранитель.

## Режимы
| Режим | Поведение | Когда |
|---|---|---|
| `Off` | выключено | по выбору / разряд батареи < 10 % |
| `Ambient` | «дыхание» выбранным цветом (по умолчанию голубой) | **только на стоянке** (законность), декоративно |
| `Follow` | тёплый белый подсвет дороги, включается вместе с основным светом, яркость растёт со скоростью | езда в темноте (по умолчанию) |
| `RoadMark` | бегущие штрихи вдоль бортов, скорость синхронна со скоростью велосипеда — эффект «неподвижной разметки» под колёсами | езда, демонстрация |

## Наложения (поверх любого режима)
- **Поворот:** янтарная «бегущая волна» спереди назад по борту поворота, синхронно с передними/задними поворотниками (общая фаза `vstate::blinkOn`). Аварийка — оба борта.
- **Стоп:** красный «хвост» — последние 8 светодиодов каждого борта.
- **Будущее (UG-05):** «проекция» поворота на асфальт — расширяющаяся дуга сзади при повороте; предупреждение о низком заряде — короткая красная вспышка раз в 30 с на стоянке.

## Ограничения
- Ни синего/красно-синего, ни проблесковых эффектов во время движения. Яркость в движении ≤ 50 % по умолчанию.
- Красный — только в задней части бортов.
