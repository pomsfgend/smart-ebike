# Кнопки на руле

## Вариант PCA9555 (по умолчанию)
```
Пульт: общий провод ── GND ;  кнопка k ── P0.k PCA9555 (подтяжка 10 кОм к 3.3 В, 100 нФ на GND, TVS/ESD-диод)
PCA9555: A0..A2 = GND → 0x20 ; INT — не подключён (опрос 5 мс)
P1.6 → NPN → активный зуммер 12 В ; P1.7 → N-MOSFET (IRLZ44N) → клаксон 12 В (диод на клаксоне)
```
Расширитель на основной плате (не на руле): длинный I2C до руля ненадёжен; до руля идут жилы кнопок.

## Вариант ADC-лестница
```
3V3 ─ 10 кОм ─┬─ GPIO2 (100 нФ)
              ├─ K0 ─ 1 кОм ─ GND
              ├─ K1 ─ 3.3 кОм ─ GND
              ├─ K2 ─ 6.8 кОм ─ GND
              └─ …  (уровни разнесены ≥ 300 мВ)
```
Одновременные нажатия не различаются (кроме спец. подбора); подойдёт, если пульт уже имеет 2–3 провода.

## Вариант прямые GPIO
Только без SPI-дисплея: GPIO16/21/39/6/7, RC 1 кОм + 100 нФ, TVS.
