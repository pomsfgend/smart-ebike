# Дисплей SPI TFT 480×320 (ILI9488 3.5" / ST7796S 4")

```
ESP32-S3                 Модуль TFT
GPIO6  ─────────────────► SCK
GPIO7  ─────────────────► SDI (MOSI)
GPIO16 ─────────────────► DC/RS
GPIO21 ─────────────────► CS
EN/RC  ─────────────────► RESET   (или линия PCA9555)
GPIO39 ─[1 кОм]─ база/затвор ключа подсветки ─► LED
3V3/5V ─────────────────► VCC (по перемычке на модуле)
GND    ─────────────────► GND
SDO (MISO) — не подключать; T_CS/T_IRQ (тач) — не подключать
```
- Кабель ≤ 30–40 см; GND между каждым сигналом в шлейфе или экран; при ошибках снизить `CFG_DISPLAY_SPI_HZ` до 27 МГц.
- Корпус: IP65, окно поликарбонат 2–3 мм, уплотнитель, Gore-вент, солнцезащитный козырёк.
- Апгрейд 4.3"/5" RGB 800×480: только на своей плате или готовом модуле «ESP32-S3 + RGB-панель» (второй МК-дисплей, связь с основным по CAN/UART) — задача DISP-06.
