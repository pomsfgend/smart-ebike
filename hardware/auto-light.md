# Автосвет: датчик освещённости и переключатель

## BH1750 (GY-302) / VEML7700
```
3V3 ── VCC ; GND ── GND ; SDA/SCL ── GPIO8/9 (общая шина I2C, подтяжки на основной плате)
BH1750: ADDR → GND = 0x23 ; VEML7700: фиксированный 0x10
```
- Кабель до датчика ≤ 1 м; длиннее — снизить I2C до 100 кГц или поставить буфер P82B715/PCA9515.
- Монтаж: окно из матового поликарбоната, направлено вверх-вперёд, экранировано от собственной фары и лент.

## Вариант с фоторезистором
```
3V3 ─ LDR (GL5528) ─┬─ GPIO2 (ADC1_CH1)
                    └─ 10 кОм ─ GND ; 100 нФ параллельно
```
Требует калибровки «АЦП → лк» (таблица в NVS).

## Переключатель OFF / AUTO / ON
```
Общий контакт ── GND
Контакт AUTO ── вход модуля кнопок (PCA9555 P0.x, тип Level, действие LightAuto)
Контакт ON   ── вход модуля кнопок (PCA9555 P0.y, тип Level, действие LightOn)
OFF = оба разомкнуты
Без переключателя: одна кнопка «☀» — LightCycle (OFF → AUTO → ON)
```
Тип: трёхпозиционный тумблер ON-OFF-ON на руле или модуль кнопок с фиксацией. Средняя позиция удобнее как AUTO — тогда распайка: верх = ON, середина = AUTO (оба разомкнуты), низ = OFF → поменять назначения в таблице кнопок (`lib/buttons`, задача AL-03 / BTN-01).
