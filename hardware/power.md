# Силовая часть: пакет, предохранители, контактор, предзаряд, kill, питание «мозга»

## Принципиальная схема (упрощённо)
```
 Сборка A (18S 50 А·ч, JBD A) +──[FA 80 А DC≥80В]──┐            6 AWG, одинаковая длина
 Сборка B (18S 50 А·ч, JBD B) +──[FB 80 А DC≥80В]──┴──● BUS+
                                                      │
                                              [F_MAIN 150 А DC≥80В]
                                                      │
                                            [SD сервисный разъединитель / anti-spark]
                                                      │
              ┌───────────────────────┬───────────────┼─────────────────────────────┐
              │                       │               │                             │
      [F_AON 1 А]              [F_KILL 2 А]    ┌──────┴──────┐               ┌──────┴──────┐
              │                       │        │  K1 главный  │               │  Предзаряд  │
       D1 SS2H10 100В          ┌──[KILL NC]──┐ │  контактор   │               │ SSR/реле    │
              │                │  (красный)  │ │ DC≥150А ≥72В │               │ ≥100 В DC   │
      R 2.2Ω + TVS SMBJ70A     │             │ └──────┬──────┘               │ + R 47Ω 50Вт│
              │                ▼             ▼        │                      └──────┬──────┘
        LM5164 → 5V_AON   Катушка K1+   Реле пр.+     ●───────────── LOAD+ ─────────┘
              │                │             │        │
           LDO 3.3V      Катушка K1−    Реле пр.−     ├── Fardriver ND72530 B+  (6 AWG)
              │                │             │        ├── «зажигание» Fardriver (тонкий провод, через 1 А)
          ESP32-S3 …      Q1 drain      Q2 (NPN/MOSFET)└── DC-DC 12 В пользователя (через свой предохр.)
                         (IRL540N)     ← PCA9555 P1.0
                         gate ← GPIO1
                         гашение: D (UF4004) + стабилитрон 33 В последовательно, параллельно катушке

 BUS− (общий минус сборок, P− обеих JBD) ── ШУНТ 0.375 мОм ── GND нагрузки: Fardriver B−, DC-DC 12 В −, GND платы
 V_load: LOAD+ ─ 300 кОм ─┬─ 10 кОм ─ GND → ADS1115 A2
 KILL: второй контакт (NO при нажатии) → PCA9555 P1.1 (подтяжка 10 кОм к 3.3 В) ; AUX K1 → P1.2
```

## Компоненты
| Поз. | Описание | Выбор |
|---|---|---|
| FA, FB | предохранитель на сборку | 80 А, DC ≥ 80 В (ANN-80 и т. п.), **у клеммы сборки** (≤ 15–20 см) |
| F_MAIN | главный | 150 А, DC ≥ 80 В (ANN-150) — защищает провод 6 AWG при КЗ; ANL/MEGA 32 В — не подходят |
| SD | сервисный разъединитель | ключ-выключатель батареи ≥ 150 А DC или anti-spark разъём (XT90-S — до ~90 А длит., для 100/120 А — AS150/QS8) |
| K1 | главный контактор | DC, ≥ 150 А длит., ≥ 72 В DC (лучше ≥ 100 В), катушка 12 В, aux NO; без встроенного экономайзера (иначе — чистые 12 В) |
| Предзаряд | ключ + резистор | PhotoMOS/SSR ≥ 100 В DC ≥ 2 А **или** DC-реле ≥ 100 В DC; резистор 47 Ом 50 Вт в алюм. корпусе |
| KILL | аварийный | красный грибок / тумблер с крышкой, **NC**, 2 контакта (силовой в цепи катушек + сигнальный), IP65 |
| Q1 | ключ катушки | N-MOSFET 100 В logic-level (IRL540N), гасящая цепь D + 33 В |
| D1, TVS, LM5164 | AON | см. [../docs/core/POWER.md](../docs/core/POWER.md) |

## Провода и монтаж
- **6 AWG (13.3 мм²)** силикон: сборки → FA/FB → BUS → F_MAIN → SD → K1 → Fardriver; минус: сборки → шунт → Fardriver.
- Трассы **короткие**, «+» и «−» рядом (стяжками), без петель; перемычки сборок к BUS — одинаковые.
- Наконечники лужёные медные под 6 AWG, **обжим шестигранником** под сечение, проверка на отрыв, термоусадка с клеем; без пайки на силовых наконечниках; затяжка по моменту.
- Тонкие цепи (катушка, предзаряд, AON, kill, V_load) — 0.5–0.75 мм², каждая — со своим предохранителем у точки подключения к силовой шине.
- Ветка 12 В нагрузок — от DC-DC пользователя, сечение по току (20 А → 2.5 мм² / 14 AWG до блока предохранителей 12 В).
