# lib/core — ядро контроллера

| Файл | Назначение |
|---|---|
| `vehicle_state.*` | общее состояние + единая фаза мигания поворотников |
| `inputs.*` | опрос тормозов, поворотов, аварийки, переключателя света (антидребезг) |
| `config_store.*` | настройки в NVS |
| `comms.*` | CAN (TWAI) и UART к контроллеру мотора |
| `ota.*` | обновление по Wi‑Fi |

Документация: [`docs/core/`](../../../docs/core/README.md). Задачи: `CORE-*` в [`docs/TASKS.md`](../../../docs/TASKS.md).
