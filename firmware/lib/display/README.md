# lib/display — дисплей

| Файл | Назначение |
|---|---|
| `screens.h` | модель экранов, навигация, авто-экран зарядки, яркость подсветки (чистый C++, тесты) |
| `display_hal.h` | интерфейс бэкенда дисплея |
| `display_log.cpp` | заглушка: экраны в консоль (по умолчанию, без `USE_LVGL`) |
| `display_lvgl.cpp` | LVGL 8.3 + LovyanGFX, ILI9488 3.5" / ST7796S 4" 480×320 SPI (окружение `esp32s3_lvgl`) |
| `display.*` | задача: очередь UI от кнопок, пробег, подсветка, рендер |

Документация: [`docs/display/`](../../../docs/display/README.md). Задачи: `DISP-*`.
