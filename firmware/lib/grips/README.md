# lib/grips — подогрев ручек (12 В)

`grips_logic.h` — уровни → цель 30/35/40/45/50 °C, ПИ-регулятор, предел 55 °C, обрыв NTC → выкл, бюджет тока, таймер, отсечка по SoC (чистый C++, тесты).
`grips.*` — LEDC 200 Гц на GPIO40/47, NTC через ADS1115, общий ключ через PCA9555 P1.4.
Документация: [`docs/grips/`](../../../docs/grips/README.md). Задачи: `GRIP-*`.
