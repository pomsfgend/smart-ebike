# Быстрая зарядка GB/T DC

Модуль быстрой зарядки от станций постоянного тока с разъёмом **GB/T DC** (на основе ESP и существующего
проекта «обманки») разрабатывается **в отдельной ветке [`charger-gbt`](../../tree/charger-gbt)**.

В ветке `main` здесь только эта заглушка. Точки интеграции с основным контроллером (будут согласованы):
- ток заряда до 100 А проходит через общий шунт → учитывается счётчиком заряда (`lib/battery_meter`);
- данные двух JBD BMS (напряжения ячеек, температуры, защиты) могут использоваться зарядным модулем для ограничения тока.
